# Проект «урок 7»

## О пользователе
- Пользователя зовут Алия. Обращаться к ней по имени.
- Общение на русском языке, объяснять простыми словами.

## О проекте
Telegram-бот на Python (`bot.py`), работает через long polling (`getUpdates`).
На любое сообщение отвечает:
- временем и датой по Астане (UTC+5);
- погодой в Астане (Open-Meteo);
- курсом биткоина в $ и ₸ (CoinGecko).

Сообщения, пришедшие, пока бот был выключен, игнорируются (`skip_pending_updates`).

## Правила
- Токен бота лежит в `.env` (переменная `BOT_TOKEN`). Файл `.env` исключён из git через `.gitignore`.
  Не выводить токен в чат и не копировать его в другие файлы.
- Запуск на этом компьютере: `py bot.py` (команда `python` указывает на заглушку Windows Store).
- Зависимости: `requirements.txt` (`requests`, `python-dotenv`).
